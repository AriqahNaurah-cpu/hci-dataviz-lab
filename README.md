# HCI & DataViz Lab

Website pembelajaran interaktif berbahasa Indonesia mengenai **Human-Computer Interaction (HCI)** dan **Data Visualization**.

## Fitur
- Pengantar HCI: usability, feedback, aksesibilitas, dan konsistensi.
- Pengantar visualisasi data dan contoh grafik.
- Demo interaktif: edit nilai kunjungan mingguan dan pilih grafik batang, garis, atau diagram proporsi.
- Studi kasus: aplikasi kampus, dashboard penjualan, dan kualitas udara.
- Desain responsif, navigasi mobile, dan tombol tema.

## Cara menjalankan
Buka `index.html` langsung di browser. Website tidak memerlukan server atau library JavaScript eksternal. Google Fonts digunakan untuk font jika internet tersedia.

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `hci-dataviz-lab`.
2. Upload `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
6. Tunggu deployment selesai dan buka URL yang ditampilkan GitHub.

## Catatan
Konten ini merupakan materi pengantar umum berdasarkan judul webinar yang terlihat, bukan transkrip atau ringkasan terverifikasi dari seluruh video. Contoh data pada demo bersifat fiktif untuk tujuan pembelajaran.
